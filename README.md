# Task 2 — Data Visualization and Storytelling

## Objective
Create visualizations that convey a compelling business story. The internship task specifies Tableau/Power BI and asks for a visual report (PDF or dashboard screenshots).

## Dataset
`superstore_sales.csv` is a Superstore-style sales dataset created for this project. It contains:
- Order ID
- Order Date
- Region
- State
- Category
- Sub-Category
- Sales
- Discount
- Profit
- Month
- Year
- Profit Margin

## Visualizations
1. Monthly Sales and Profit Trend — line chart
2. Sales by Category — bar chart
3. Profit by Region — bar chart
4. Discount vs Profit — scatter plot

## Key KPIs
- Total Sales: 129,782.90
- Total Profit: 17,929.57
- Profit Margin: 13.8%
- Average Discount: 10.0%
- Highest Sales Category: Office Supplies
- Highest Profit Region: East

## Power BI steps
1. Open Power BI Desktop.
2. Select **Get Data → Text/CSV**.
3. Import `superstore_sales.csv`.
4. Create KPI cards for Sales, Profit and Profit Margin.
5. Create a line chart: Month on X-axis, Sales and Profit as values.
6. Create a bar chart: Category on axis, Sales as value.
7. Create a bar chart: Region on axis, Profit as value.
8. Create a scatter chart: Discount on X-axis and Profit on Y-axis.
9. Add a clean title such as **Sales Performance Dashboard**.
10. Export the dashboard as PDF or take dashboard screenshots.
11. Put the screenshots/PDF and this README in the GitHub repository.
